Adsterra ad code

      

        Paste each unit's code from Adsterra → Websites → your site →
        Get code, exactly as shown, script tags included. Each box is
        checked as you paste. Leave a box empty to run without that unit.
      

      

        The house limit is one popunder, one Social Bar and one banner — three
        units, no more. That ceiling is enforced by the site's tests, not just
        by this screen.
      

    


    


    

      
ads.txt

      

        One line, from Adsterra → Websites → ads.txt. Served at
        /ads.txt. Without it, advertisers that verify ownership
        will not bid, and nothing on the site looks broken while that happens.
      

      
      

    


    

      
Save

      

        Saved to .env, which is gitignored and stays on this
        machine. The live site does not read it. For the real
        site, put the same values in Cloudflare Pages → Settings → Environment
        variables, or in GitHub → Settings → Secrets.
